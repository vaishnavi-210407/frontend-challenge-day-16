# 🛒 Cart System

A responsive Cart System built using HTML, CSS, and JavaScript.

## 🚀 Features
- Add to Cart functionality
- Quantity management
- Remove cart items
- Dynamic total price calculation
- Responsive UI

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

## 📂 Project Flow
1. Created cart array structure
2. Added products to cart
3. Implemented quantity controls
4. Calculated total dynamically
5. Added remove item functionality

## 🎯 Learning Outcome
- Improved JavaScript array handling
- Learned cart management logic
- Practiced dynamic DOM updates
- Better understanding of E-commerce functionality
